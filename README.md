# Martian Froggies NFT Minting DApp

🛸 A simple HTML + React + Ethers.js DApp that allows users to mint Martian Froggies NFTs directly from the browser.

## Features
- Connects with MetaMask, WalletConnect, and Phantom (EVM support)
- Allows minting 1–50 NFTs
- Dynamic cost and balance calculations
- Status updates and error handling

## Live Demo
👉 [View it live here](https://yourusername.github.io/martian-froggies-mint-dapp/martian-froggies-nft-mint.html)

## How to Run Locally
Just open the `martian-froggies-nft-mint.html` file in your browser.
